# 星问卷

问卷星风格的在线问卷平台复现：创建问卷、发布链接、填写回收、统计报表。数据保存在浏览器本地，无需后端即可完整体验。

## 功能

- 首页、模板库、定价页
- 注册 / 登录（含演示账号）
- 从空白或模板创建问卷（调查、表单、考试、投票、测评）
- 10 种题型：单选、多选、填空、简答、下拉、评分、量表、NPS、日期、排序
- 编辑器：题目增删改、上移下移、必填、显示逻辑、外观与收集设置
- 填写页：进度条、密码、防重复、主题色
- 报表：饼图 / 条形图、原始答卷、导出 CSV

## 本地运行

```bash
cd wenjuanxing
npm install
npm run dev
```

浏览器打开 http://localhost:5173

演示账号：`demo@xingwenjuan.com` / `demo123`
